Severn Ridge Precision is a fictional 22-person CNC shop. Every export below is synthetic; the requirements, objectives, point values and POA&M rules are the real ones from NIST and 32 CFR 170.

Score over time

SPRS method: start at 110, subtract 1, 3 or 5 for each requirement not met. Below 88, or with any 3- or 5-point miss, no POA&M is allowed.

Where the evidence comes from

Each of the 320 assessment objectives is decided by the strongest evidence available. A machine export beats a signed record, and both beat policy text.

How it works

The same pipeline runs every month. Nothing here is a questionnaire: each answer is computed from a file, and each file is hashed into a bundle that points at last month's bundle.

Export

Pull what already exists: Entra users and policies, Intune devices, Defender scans, firewall rules, audit settings, LMS records, scanned logs.

Collect

Each collector reads one source and decides only the objectives it claims, MET or NOT MET, with a reason a person can check.

Age out

Every source has a maximum age. A stale export or an overdue drill counts as NOT MET, the way an assessor would treat it.

Score

Objectives roll up to requirements. Points, partial credit for MFA and FIPS, and POA&M eligibility follow 32 CFR 170.24 and 170.21.

Seal

Every file's SHA-256 goes into a bundle with the results. The bundle's hash includes last month's hash, so history can't be quietly edited.
